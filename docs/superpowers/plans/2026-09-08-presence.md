# Presence — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS menu bar app that keeps the Microsoft Teams status "Available" (green) while turned on, keeping the system idle counter low and showing the user that it's actually working.

**Architecture:** A `PresenceController` (`@MainActor`) runs a 30s loop that declares user activity via IOKit and **verifies** the result by reading `HIDIdleTime`. If the declaration isn't enough, it escalates to synthetic input (F15 key). Every system dependency comes in through a protocol, so the entire loop is testable without touching IOKit.

**Tech Stack:** Swift 6.3, SwiftUI (`MenuBarExtra`), IOKit (`IOPMAssertionDeclareUserActivity`, `IOHIDSystem`), CoreGraphics (`CGEvent`), ServiceManagement (`SMAppService`), Swift Package Manager, XCTest.

**Spec:** `docs/superpowers/specs/2026-09-08-presence-design.md`

## Global Constraints

- **Platform:** macOS 14+, arm64. `platforms: [.macOS(.v14)]` in `Package.swift`.
- **Language mode:** Swift 5 (`swiftLanguageModes: [.v5]`). Swift 6's strict concurrency imposes a steep cost around IOKit's C APIs, with no benefit here.
- **App Sandbox:** off. `IOHIDSystem` and `CGEvent.post` don't work under sandbox.
- **Bundle ID:** `com.rootless.presence`, fixed. Changing it invalidates the Accessibility permission already granted.
- **`LSUIElement`:** `true`. No Dock icon, no window.
- **Signing:** ad-hoc (`codesign --sign -`) by default; the script accepts `DEV_ID` in the environment to sign with a Developer ID. Every ad-hoc rebuild revokes the Accessibility permission — expected during development.
- **Language:** all UI text visible to the user in English. Code identifiers in English.
- **No external dependencies.** System frameworks only.
- **Log:** `OSLog` with subsystem `com.rootless.presence`.
- **Loop constants:** 30s interval, 1s verification delay, 5s idleness threshold, escalation after 3 consecutive failures.

`Sources/PresenceCore/IdleReader.swift`:

```swift
import Foundation
import IOKit

/// Reads the system's input idle counter.
///
/// It's the same value that `ioreg -c IOHIDSystem | grep HIDIdleTime` shows,
/// in nanoseconds, and it's the number Teams checks to decide whether you're
/// away.
public protocol IdleReading {
    func idleSeconds() -> TimeInterval
}

public struct IdleReader: IdleReading {

    public init() {}

    public func idleSeconds() -> TimeInterval {
        var iterator: io_iterator_t = 0
        let matching = IOServiceMatching("IOHIDSystem")
        guard IOServiceGetMatchingServices(kIOMainPortDefault, matching, &iterator) == KERN_SUCCESS else {
            return 0
        }
        defer { IOObjectRelease(iterator) }

        let entry = IOIteratorNext(iterator)
        guard entry != 0 else { return 0 }
        defer { IOObjectRelease(entry) }

        var unmanaged: Unmanaged<CFMutableDictionary>?
        guard IORegistryEntryCreateCFProperties(entry, &unmanaged, kCFAllocatorDefault, 0) == KERN_SUCCESS,
              let properties = unmanaged?.takeRetainedValue() as? [String: Any],
              let nanoseconds = properties["HIDIdleTime"] as? NSNumber
        else {
            return 0
        }

        return nanoseconds.doubleValue / 1_000_000_000
    }
}
```

```swift
import Foundation
import IOKit.pwr_mgt

public enum ActivityDeclarerError: Error {
    case ioKitFailure(Int32)
}

/// Declares to the power manager that the user is active.
///
/// It's the same API `caffeinate -u` uses. It requires no macOS permission
/// and doesn't inject input — but, being declarative, there's no documented
/// guarantee that it zeroes out `HIDIdleTime`. That's why the app verifies.
public protocol ActivityDeclaring {
    func declare() throws
}

public final class ActivityDeclarer: ActivityDeclaring {

    private var assertionID = IOPMAssertionID(0)

    public init() {}

    /// Exposed only for the assertion-reuse test.
    public var assertionIDForTesting: UInt32 { assertionID }

    public func declare() throws {
        let name = "Presence: keeping status Available" as CFString
        let result = IOPMAssertionDeclareUserActivity(name, kIOPMUserActiveLocal, &assertionID)
        guard result == kIOReturnSuccess else {
            throw ActivityDeclarerError.ioKitFailure(result)
        }
    }
}
```

```swift
import Foundation
import PresenceCore

// Experiment: does the power assertion zero out HIDIdleTime?
//
// Waits for the machine to actually go idle for 60s — without relying on the
// operator staying still in an agreed-upon window, which is what
// contaminated the manual measurement taken during design.

let reader = IdleReader()
let declarer = ActivityDeclarer()

let threshold: TimeInterval = 60
let deadline = Date().addingTimeInterval(3600)

print("waiting for \(Int(threshold))s of real idleness (up to 1h)...")

while Date() < deadline {
    guard reader.idleSeconds() >= threshold else {
        Thread.sleep(forTimeInterval: 5)
        continue
    }

    let before = reader.idleSeconds()
    do {
        try declarer.declare()
    } catch {
        print("FAILED to declare activity: \(error)")
        exit(1)
    }
    Thread.sleep(forTimeInterval: 1)
    let after = reader.idleSeconds()

    print(String(format: "idle BEFORE = %.1fs | AFTER = %.1fs", before, after))

    if after < 5 {
        print("RESULT: the assertion DOES zero out the counter. .declared mode is viable.")
    } else if after >= before {
        print("RESULT: the assertion does NOT zero out the counter. The app will live in .synthetic.")
    } else {
        print("RESULT: inconclusive (partial drop). Repeat the probe.")
    }
    exit(0)
}

print("giving up: the machine wasn't idle for \(Int(threshold))s within 1 hour")
exit(2)
```

`Sources/PresenceCore/SyntheticInput.swift`:

```swift
import AppKit
import ApplicationServices
import CoreGraphics

/// Injects a harmless keyboard event to zero out the idle counter.
///
/// F15 (`kVK_F15`, 0x71) doesn't exist on Mac keyboards and no app reacts to it.
public protocol SyntheticInputting {
    var isPermitted: Bool { get }
    func tap() -> Bool
    func requestPermission()
    func openPermissionSettings()
}

public struct SyntheticInput: SyntheticInputting {

    private let keyCode: CGKeyCode = 0x71

    public init() {}

    public var isPermitted: Bool {
        AXIsProcessTrusted()
    }

    /// Posts to `.cghidEventTap`, not `.cgSessionEventTap`. Events injected
    /// into the session tap may not reach the IOHIDSystem and therefore may
    /// not reset the counter — which would make this fallback useless without
    /// giving any error signal.
    public func tap() -> Bool {
        guard let source = CGEventSource(stateID: .hidSystemState),
              let down = CGEvent(keyboardEventSource: source, virtualKey: keyCode, keyDown: true),
              let up = CGEvent(keyboardEventSource: source, virtualKey: keyCode, keyDown: false)
        else {
            return false
        }
        down.post(tap: .cghidEventTap)
        up.post(tap: .cghidEventTap)
        return true
    }

    /// Shows the system dialog requesting Accessibility. It only appears once
    /// per process; after that the user has to go to Settings.
    public func requestPermission() {
        let options = [kAXTrustedCheckOptionPrompt.takeUnretainedValue() as String: true] as CFDictionary
        _ = AXIsProcessTrustedWithOptions(options)
    }

    public func openPermissionSettings() {
        let path = "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility"
        guard let url = URL(string: path) else { return }
        NSWorkspace.shared.open(url)
    }
}
```

`Sources/PresenceCore/LockMonitor.swift`:

```swift
import Foundation

/// Notifies when the screen is locked and unlocked.
///
/// This matters because declaring activity wakes the display (documented in
/// the `caffeinate` man page, `-u` flag). Without pausing while the screen is
/// locked, the app would light up the monitor all night long.
public protocol LockObserving: AnyObject {
    var onLock: (() -> Void)? { get set }
    var onUnlock: (() -> Void)? { get set }
    func start()
}

public final class LockMonitor: LockObserving {

    public var onLock: (() -> Void)?
    public var onUnlock: (() -> Void)?

    public init() {}

    public func start() {
        let center = DistributedNotificationCenter.default()
        center.addObserver(
            forName: Notification.Name("com.apple.screenIsLocked"),
            object: nil,
            queue: .main
        ) { [weak self] _ in
            self?.onLock?()
        }
        center.addObserver(
            forName: Notification.Name("com.apple.screenIsUnlocked"),
            object: nil,
            queue: .main
        ) { [weak self] _ in
            self?.onUnlock?()
        }
    }
}
```

```swift
import Foundation

public enum PresenceState: Equatable {
    /// Toggle off. No action.
    case off
    /// Loop running.
    case active
    /// Needs synthetic input, but Accessibility permission hasn't been granted.
    case blocked
    /// Screen locked. The toggle stays on, the loop is suspended.
    case pausedLocked
}

public enum ActivityMode: Equatable {
    /// IOKit power assertion. No permissions.
    case declared
    /// Synthetic F15 key. Requires Accessibility.
    case synthetic
}

public enum AutoOffInterval: String, CaseIterable, Identifiable {
    case never
    case hour1
    case hours4
    case hours8

    public var id: String { rawValue }

    public var seconds: TimeInterval? {
        switch self {
        case .never: return nil
        case .hour1: return 3600
        case .hours4: return 4 * 3600
        case .hours8: return 8 * 3600
        }
    }

    public var label: String {
        switch self {
        case .never: return "Never"
        case .hour1: return "1 hour"
        case .hours4: return "4 hours"
        case .hours8: return "8 hours"
        }
```

```swift
import Foundation

/// Injectable clock. Auto-off uses wall-clock time, so the tests need to be
/// able to jump hours ahead without actually waiting for them.
public protocol DateProviding {
    var now: Date { get }
}

public struct SystemDate: DateProviding {
    public init() {}
    public var now: Date { Date() }
}

/// Injectable wait, so the 1s verification delay doesn't make the test suite
/// slow.
public protocol Sleeping {
    func sleep(seconds: TimeInterval) async
}

public struct SystemSleeper: Sleeping {
    public init() {}
    public func sleep(seconds: TimeInterval) async {
        try? await Task.sleep(nanoseconds: UInt64(seconds * 1_000_000_000))
    }
}
```

```swift
final class FakeDeclarer: ActivityDeclaring {

    func declare() throws {

        if shouldThrow { throw ActivityDeclarerError.ioKitFailure(-1) }

final class FakeIdleReader: IdleReading {
    var values: [TimeInterval]
    private var index = 0

    init(values: [TimeInterval]) { self.values = values }

    func idleSeconds() -> TimeInterval {
        let value = values[min(index, values.count - 1)]
        index += 1
        return value
    }
```

```swift
import Foundation

/// Orchestrates the loop that keeps the idle counter low.
///
/// Every system dependency comes in through a protocol, so the entire loop
/// runs in tests without touching IOKit and without waiting on real time.
@MainActor
public final class PresenceController: ObservableObject {

    @Published public private(set) var mode: ActivityMode = .declared
    @Published public private(set) var lastIdle: TimeInterval = 0
    @Published public var autoOff: AutoOffInterval

    /// discovery and the next session already starts in the right mode.
    public var onModeChange: ((ActivityMode) -> Void)?

    private let declarer: ActivityDeclaring
    private let idleReader: IdleReading
    private let input: SyntheticInputting
    private let date: DateProviding
    private let sleeper: Sleeping
    private let initialMode: ActivityMode

    private var consecutiveHighIdle = 0
    private var startedAt: Date?

        idleReader: IdleReading,
        input: SyntheticInputting,
        date: DateProviding,
        sleeper: Sleeping,
        autoOff: AutoOffInterval,
        initialMode: ActivityMode = .declared

        self.declarer = declarer
        self.idleReader = idleReader
        self.input = input
        self.date = date
        self.sleeper = sleeper
        self.autoOff = autoOff
        self.initialMode = initialMode
        self.mode = initialMode
    }

    public func turnOn() {
        state = .active
        mode = initialMode
        consecutiveHighIdle = 0
        startedAt = date.now
    }

    public func turnOff() {
        state = .off
        consecutiveHighIdle = 0
        startedAt = nil
    }

    public func tick() async {
        guard state == .active || state == .blocked else { return }

        do {
            try declarer.declare()
        } catch {
            // Handled in Task 5.
        }

        await sleeper.sleep(seconds: Self.verifyDelay)
        lastIdle = idleReader.idleSeconds()
```

```swift
    public func tick() async {
        guard state == .active || state == .blocked else { return }

        var declareFailed = false
        do {
            try declarer.declare()
        } catch {
            declareFailed = true
        }

        if mode == .synthetic {
            guard input.isPermitted else {
                state = .blocked
                return
            }
            state = .active
            _ = input.tap()
        }

        await sleeper.sleep(seconds: Self.verifyDelay)
        lastIdle = idleReader.idleSeconds()

        if declareFailed && mode == .declared {
            escalate()
            return
        }

        if lastIdle < Self.idleThreshold {
            consecutiveHighIdle = 0
        } else {
            consecutiveHighIdle += 1
            if consecutiveHighIdle >= Self.failuresBeforeEscalation && mode == .declared {
                escalate()
            }
        }
    }

    /// Starts injecting input for real. If permission hasn't been granted, it
    /// requests it once and assumes `blocked` — the app doesn't pretend to be
    /// working.
    private func escalate() {
        mode = .synthetic
        onModeChange?(.synthetic)
        consecutiveHighIdle = 0
        if input.isPermitted {
            state = .active
        } else {
            input.requestPermission()
            state = .blocked
        }
    }
```

```swift
import Foundation

/// Persists the user's choices.
///
/// The on/off state is deliberately **not** persisted: the app always starts
/// off and never turns itself on.
public final class Preferences {

    private enum Key {
        static let autoOff = "autoOffInterval"
        static let startMode = "verifiedActivityMode"
    }

    private let defaults: UserDefaults

    public init(defaults: UserDefaults = .standard) {
        self.defaults = defaults
    }

    public var autoOff: AutoOffInterval {
        get {
            guard let raw = defaults.string(forKey: Key.autoOff),
                  let value = AutoOffInterval(rawValue: raw)
            else {
                return .hours8
            }
            return value
        }
        set {
            defaults.set(newValue.rawValue, forKey: Key.autoOff)
        }
    }

    /// The mode the app should start in, based on what's already been
    /// verified on this machine.
    public var startMode: ActivityMode {
        get {
            defaults.string(forKey: Key.startMode) == "synthetic" ? .synthetic : .declared
        }
        set {
            defaults.set(newValue == .synthetic ? "synthetic" : "declared", forKey: Key.startMode)
        }
    }
}
```

```swift
import AppKit
import Foundation
import PresenceCore

/// Owner of the loop: turns it on, off, and keeps the 30s cadence.
///
/// Lives in the app layer, not in `PresenceCore`, because it deals with
/// process lifecycle (App Nap) — something the controller's tests shouldn't
/// even see.
@MainActor
final class PresenceRunner {

    let controller: PresenceController

    private let lockMonitor: LockObserving
    private let preferences: Preferences
    private var loop: Task<Void, Never>?
    private var activityToken: NSObjectProtocol?

    init(controller: PresenceController, lockMonitor: LockObserving, preferences: Preferences) {
        self.controller = controller
        self.lockMonitor = lockMonitor
        self.preferences = preferences
    }

    func start() {
        controller.onModeChange = { [weak self] mode in self?.preferences.startMode = mode }
        lockMonitor.onLock = { [weak self] in self?.controller.screenLocked() }
        lockMonitor.onUnlock = { [weak self] in self?.controller.screenUnlocked() }
        lockMonitor.start()
    }

    func toggle() {
        controller.state == .off ? turnOn() : turnOff()
    }

    func setAutoOff(_ interval: AutoOffInterval) {
        controller.autoOff = interval
        preferences.autoOff = interval
    }

    private func turnOn() {
        controller.turnOn()

        // Without this, App Nap coalesces the timers of a background menu bar
        // app, and a 30s cycle can turn into minutes — plenty of time for
        // Teams to turn yellow before the next tick.
        activityToken = ProcessInfo.processInfo.beginActivity(
            options: .userInitiated,
            reason: "Presence keeping the status Available"
        )

        loop = Task { [weak self] in
            while !Task.isCancelled {
                guard let self else { return }
                await self.controller.tick()
                // Auto-off turns things off internally; the runner follows along.
                if self.controller.state == .off {
                    self.turnOff()
                    return
                }
                try? await Task.sleep(nanoseconds: UInt64(PresenceController.cycle * 1_000_000_000))
            }
        }
    }

    private func turnOff() {
        loop?.cancel()
        loop = nil
        controller.turnOff()
        if let activityToken {
            ProcessInfo.processInfo.endActivity(activityToken)
        }
        activityToken = nil
    }
}
```

```swift
import ServiceManagement

/// Registers the app to launch along with the system.
///
/// `SMAppService.mainApp` stores the bundle's location. Registered from
/// `.build/release`, the login item breaks as soon as that folder disappears
/// — that's why the Makefile's `install` target copies to `/Applications`
/// first.
enum LoginItem {

    static var isEnabled: Bool {
        SMAppService.mainApp.status == .enabled
    }

    @discardableResult
    static func setEnabled(_ enabled: Bool) -> Bool {
        do {
            if enabled {
                try SMAppService.mainApp.register()
            } else {
                try SMAppService.mainApp.unregister()
            }
            return true
        } catch {
            return false
        }
    }
}
```

````markdown
# Presence

Menu bar app that keeps the Microsoft Teams status "Available" while it's on.

## The problem

Teams marks you as away based on the system's idle counter (`HIDIdleTime`).
Stepping away from your PC for a few minutes turns the status yellow.

## How it works

Every 30 seconds the app declares user activity via IOKit
(`IOPMAssertionDeclareUserActivity` — the same API `caffeinate -u` uses) and
then **checks** `HIDIdleTime` to see whether the declaration took effect. If
the counter doesn't budge for three cycles in a row, the app escalates to
injecting a synthetic F15 key, which doesn't exist on Mac keyboards and which
no app reacts to. That extended mode requires Accessibility permission.

The menu shows the real idle counter, so you can see it's working instead of
just hoping.

## Usage

```bash
make test      # run the suite
make bundle    # build Presence.app
make install   # install to /Applications
make probe     # experiment: does the power assertion zero out the counter on this machine?
```

## Details that matter

- While active, there's no screensaver and no automatic lock. That's the
  price of appearing active.
- With the screen locked the app pauses on its own: declaring activity would
  wake the display, and in that state Teams marks you away anyway. Once
  unlocked, it resumes.
- Every ad-hoc-signed rebuild revokes the Accessibility permission. For a
  stable identity: `DEV_ID="Developer ID Application: ..." make bundle`.
- The app always starts off. It never turns itself on.

## Diagnostics

```bash
log show --predicate 'subsystem == "com.rootless.presence"' --last 1h
```
````

## Notes for whoever executes this

**Order matters.** Tasks 1-2 resolve the technical uncertainty that drove the
whole architecture. If the Task 2 probe says the power assertion does **not**
zero out the counter, nothing in the plan changes — the state machine already
covers that case; the only difference is that the app will live in
`.synthetic` and will request Accessibility permission right on first use.

**Task 3 deliberately has no automated tests.** Without Accessibility
permission, `CGEvent.post` fails silently and returns success. A test
asserting "the tap worked" would be a false positive, which is worse than no
test at all. The real verification is the controller's loop reading
`HIDIdleTime` afterward — the same mechanism that protects the user protects
the code.

**If a controller test gets slow**, someone swapped `NoSleep` for
`SystemSleeper` somewhere. The whole suite runs in under 5 seconds, aside from
the `IdleReader` integration test, which deliberately sleeps for 2 seconds.
